## 🚀 Features
* User Registration & Login: Secure authentication with password hashing and CSRF protection

* Blog Post Management: Create, edit, and delete posts (CRUD operations)

* Categories & Tags: Organize posts for easy navigation and filtering

* *Comment System: Readers can engage and discuss each post

* User Profiles: Personal bios and avatars for each member

* Admin Dashboard: Django Admin panel for managing content, users, and comments

* Post Search: Find posts with a robust search feature

* Responsive UI: Built with Bootstrap or custom CSS for seamless experience on all devices

## 🛠️ Tech Stack
Component	Technology
Backend	Django (Python)
Database	SQLite (default), PostgreSQL, MySQL
Frontend	HTML, CSS, Bootstrap

## 📚 Usage
* Register or log in to access all features.

* Create, edit, and delete your blog posts.

* Organize, search, and filter posts by categories and tags.

* Add comments and interact with the community.

* Update your profile and avatar.

* Access the Django Admin at /admin/ for comprehensive site management.
